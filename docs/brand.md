# Work Learn 品牌标志

## 标志概念

Work Learn 的标志是一个开放的 `W` 形路径：

- 左侧路径代表用户提出问题、输入工作语境；
- 中间路径代表 AI 对话和上下文转换；
- 右侧路径代表把表达带回下一次工作，形成学习复用。

它不是一个封闭徽章，而是一条可以继续向前的路径，表达 Work Learn 的核心闭环：

```text
真实工作 -> AI 对话 -> 提取语料 -> 下一次复用
```

## 标志文件

- `work-learn-mark.svg`：96 x 96 的完整品牌标志，用于落地页、应用入口和社交分享；
- `favicon.svg`：32 x 32 的浏览器图标版本。

源文件目前位于 `work-learn-landing/public/brand/` 和 `work-learn-landing/public/`。后续如果增加桌面端或 Skill 图标，应继续使用同一条 `W` 路径，不重新设计第二套符号。

## 颜色

- Ink：`#171918`，主背景和文字；
- Learning Green：`#B8F23E`，品牌强调色；
- Soft White：`#EAF4E8`，深色背景上的辅助线条。

浅色页面上使用 Ink 标志底，深色页面上也保持同一结构。避免添加渐变、阴影或其他强调色。

## 使用规则

- 最小完整标志尺寸建议为 20 x 20；
- 标志周围保留至少一个标志高度的安全空间；
- 标志可单独使用，也可与 `work learn` 小写字标组合；
- 不拉伸、不倾斜、不改变路径比例；
- 不把绿色路径替换成紫色渐变或多色渐变；
- 不在标志上叠加文字、状态点或装饰标签。
