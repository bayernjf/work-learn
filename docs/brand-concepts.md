# Work Learn Logo Concepts

当前主标志继续使用 `work-learn-mark.svg`。本组是三个备用的 `W + L` 方向，用于比较品牌符号的结构和小尺寸识别度。

## Concept 01: Tail

`W` 的右侧笔画继续下坠并向左折回，形成 `L`。识别最直接，也最接近当前标志，适合产品主标志。

文件：`work-learn-concept-01-tail.svg`

## Concept 02: Baseline

`W` 与 `L` 共用一条底线。整体更稳定、更像字标，适合文档页、网站导航和长期品牌系统。

文件：`work-learn-concept-02-baseline.svg`

## Concept 03: Axis

左侧建立一条共享主轴，把 `L` 作为底层骨架，再叠加 `W` 的学习路径。小尺寸下更像应用图标，符号感最强。

文件：`work-learn-concept-03-axis.svg`

## 共同规范

- Ink：`#171918`；
- Learning Green：`#B8F23E`；
- Soft White：`#EAF4E8`；
- 不使用渐变、阴影和额外强调色；
- 三个方案都保留同一套圆角、线宽和安全空间逻辑。
