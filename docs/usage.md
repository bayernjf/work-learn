# 使用手册

接入配置见 [MCP Agent 接入](mcp-agent-setup.md)。本文只讲装好之后怎么用。

Work Learn 没有自己的对话界面。你照常用 Claude Code、Codex、CodeBuddy 这些 agent 干活，在需要的时候用自然语言让它保存 —— Skill 负责判断该存什么，MCP 工具负责存。

## 保存学习材料

在对话里直接说，不需要记命令：

> 整理刚才这段对话，把有用的英语保存到我的语料库。

其它等效说法：「提取值得学习的英语表达」、「记录我刚才犯的错误」、「把这次技术讨论加入我的语料库」。

Skill 会先建立 session（对应当前这段对话），然后把它抽出来的每一条按固定格式打给你看，再保存：

```
Worth learning: 待学的表达或搭配
Original:       原话
Better:         更自然的说法
Why:            一句话解释差异
Reuse:          一个用上它的新句子
Vocabulary:     值得记的单词
Tags:           2-4 个标签
```

展示是让你看清它抽了什么，不是等你批准 —— 你既然让它存，它就会存。一条材料一次 `save_material` 调用，不会把多条揉进一次。

**它可能拒绝保存。** 如果这段对话整个是中文的、或者英文很平常，Skill 会告诉你这里没有值得存的内容，并且不保存。这是设计行为：往语料库里塞一条弱材料的代价比不存更大，它会进复习队列，还什么都教不了你。这时它通常会建议改存问题翻译。

## 保存问题和它的英文说法

这是独立于学习材料的另一条线：保留你的原始提问（通常是中文）加上 agent 给出的地道英文说法。**不进复习队列**，用于日后搜索和回想。

三种用法：

- **单条保存** —— 「把这个问题和它的英文翻译存下来」
- **自动模式** —— 「以后我问的每个问题都存下来」。之后每一轮它都会自动翻译并保存，不再逐次询问。
- **关掉** —— 「停」、「够了」、「不用存了」

自动模式默认会把英文说法打出来，一行，没有标签和确认信息。不想看就说「静默」或「别显示」，它会继续保存但完全不出声。

## 搜索

> 我以前存过 decouple 这个词吗？

或者「搜一下我语料库里关于 migration 的内容」。不给关键词就返回全部，按时间倒序。Web 端也有搜索框。

## 复习

> 今天有什么要复习的？

Agent 会拉出到期的条目逐条问你，你确认记住了它就标记完成。Web 端首页也有同样的每日复习区。

**当前的机制要说清楚：** 每保存一条材料就生成一个复习项，立即到期（不是隔几天）。标记掌握之后这一条就永久完成，不会再回到队列。所以现在是一次性清空的待复习列表，还不是真正的间隔重复 —— 不要指望它按 1 天、3 天、7 天的节奏把同一条再推给你。

## Web 端

`https://work-learn.pages.dev`（或你自己的域名）用来看和管，不用来存：

- 语料库：全部材料，可搜索、可按新旧排序
- 每日复习：到期条目，标记掌握
- Personal access token：新建、吊销、删除
- Cloud sync 状态：查看云端材料、提问、复习和删除记录数量，以及最近保存时间
- Agent 接入引导：就是那个配置面板

## CLI 什么时候用

`learn` 命令行是给 Skill 覆盖不到的场景兜底的，日常用不上：

- **agent 装不了 Skill / 连不上 MCP** —— `learn capture` 从 stdin 或剪贴板采集，本地先脱敏再入库
- **想要纯本地** —— CLI 和 stdio MCP 默认只读写 `~/.work-learn/work-learn.db`，不需要 token，也不需要连网
- **要备份或用别的工具看** —— `learn export` 按天导出 markdown 到 `~/.work-learn/notes/`
- **本地攒的要推到云端** —— `learn sync`

命令和参数见 [CLI 与 MCP 接入](cli-and-mcp.md)。

## 九个工具在做什么

平时不用直接调，但看到 agent 的工具调用卡片时能对上：

| 工具 | 对你意味着 |
| --- | --- |
| `create_session` | 为当前这段对话建一个会话，后面存的东西都挂在它下面 |
| `save_material` | 存一条学习材料，同时生成一个复习项 |
| `save_question_translation` | 存一对「你的提问 + 英文说法」，不进复习队列 |
| `search_corpus` | 搜你存过的材料 |
| `get_review_items` | 取到期的复习条目 |
| `mark_mastered` | 把一条复习项标记为已掌握 |
| `snooze_review` | 把一条复习项延后，默认明天再看 |
| `generate_practice` | 用一条或最近几条材料生成练习提示，由 Agent 带你练 |
| `get_user_patterns` | 汇总近期高频表达、纠错、词汇和下一步练习建议 |
| `record_reuse` | 检查当前英文里是否自然用到了已保存表达，并记录真实复用 |

## 隐私边界

- 它只读当前对话里已经可见的内容，不会去翻历史记录，也不会后台上传对话。
- API key、token、密码、私钥在保存时会被替换掉；但不要指望这层兜底 —— 别主动让它保存含密钥的片段。
- 只用本地模式的话数据不出机器。配了 token 才会走线上 API。
